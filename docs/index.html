What it does

Menu bar only

A waveform while it plays, circling arrows when it reconnects. Nothing in the Dock.

Shows what is playing

The track under the station name, read from the stream itself.

Any stream

HLS, Icecast MP3 or AAC, and playlist links it resolves for you.

Light

480 KB on disk, 15 MB of memory when idle.

Build it

No installer. One command per platform.

macOS

macOS 14 or later, Command Line Tools.

# builds build/Radio.app and launches it
git clone https://github.com/Jostein/Radio.git
cd Radio
make run

Linux

Rust, ffmpeg, GTK 3 and libayatana-appindicator. Runs under GNOME (with the AppIndicator extension), KDE Plasma and Waybar. Arch / Omarchy users can build the package in Platforms/packaging/arch.

# Debian / Ubuntu
sudo apt install build-essential libgtk-3-dev libayatana-appindicator3-dev \
  libasound2-dev libxdo-dev pkg-config ffmpeg

cd Platforms
cargo run -p radio --release

Windows

Rust and ffmpeg from winget, plus the MSVC tools rustup offers.

# PowerShell
winget install Rustlang.Rustup
winget install Gyan.FFmpeg
cd Platforms
cargo run -p radio --release

The macOS bundle is ad-hoc signed for local use, not notarized.

Three platforms

macOS, Linux and Windows, from one small codebase. The Mac build is the one in daily use; Linux and Windows are younger, and both have now run.
