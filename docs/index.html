Internet radio in your menu bar.

A tiny macOS app that plays your stations without a window, a browser tab, or a Dock icon. It comes with the best radio already built in — FIP Reggae — and takes any stream URL you add.

Small app, fussy about the right things

Everything it does is one menu click away, and it keeps playing when the stream misbehaves.

Menu bar only

One status item. A waveform while it plays, circling arrows while it reconnects, and nothing in your Dock.

Shows what is playing

The current track appears under the station name, read from the stream itself or from a feed the station publishes. Feeds are found automatically, so a station you add is covered without configuring anything.

Plays with your media keys

The station and track also appear in macOS Now Playing, so Control Center, the keyboard keys and AirPods can pause and resume.

HLS and direct streams

Plays .m3u8 HLS streams and plain Icecast MP3 or AAC URLs, straight from the menu.

Playlist links welcome

Paste an .m3u or .pls URL and it fetches the playlist, finds the stream inside and plays that.

Reconnects on its own

Dropped or stalled streams are rebuilt with exponential backoff — 1s up to 30s — and a watchdog catches silence that never reports an error.

Handles sleep and wake

Waking your Mac rejoins the live stream instead of trusting a connection that froze overnight. Paused stays paused.

Remembers your volume

Set the slider once and it is still there next launch, at 100% out of the box.

Build it

The app is a small SwiftPM project. There is no installer and no Apple Developer account involved — it builds into a normal app bundle.

  1. Clone and build. 
    # needs macOS 14+ and the Xcode Command Line Tools
git clone https://github.com/Jostein/Radio.git
cd Radio
make run
  2. Click the radio-waves icon in the menu bar, choose Add Station…, and give it a title and a stream URL.
  3. Optional: run make app and drag build/Radio.app into /Applications to keep it around.

Requires macOS 14 Sonoma or later. The app is ad-hoc signed for local use — it runs on your Mac, but it is not notarized for wider distribution.
